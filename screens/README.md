# Скриншоты платформы для 3D-сцен

Положи сюда PNG с ТОЧНЫМИ именами — панели подхватятся автоматически:

- `kpi-approval.png` — экран «Согласование KPI» (hub.mnu.kz/kpi)
- `kpi-matrix.png` — таблица «Все 22 показателя» с публикационной лестницей
- `mind-reports.png` — сетка обложек «MIND Reports»
- `mind-talks.png` — сетка афиш «MIND Talks»

Платформа за Microsoft SSO — снять их автоматически нельзя.
